---
title: Select bindings
focus: App.tsazor
---

`selected` is `"mother"`, the dropdown shows the first option. Bind it:

```tsazor
<select @bind="selected">
```

The dropdown starts at the right option, and choosing another updates the paragraph. As in
Blazor, the select's value is applied after its options have been rendered (and re-applied
when they change), so options generated by `@foreach` are no problem.

> **Coming from Blazor:** Blazor converts the selected value to the field's type — an `int`
> or an enum field just works. Tsazor's `@bind` assigns the option's value as it is: a
> string. Use string ids (as here), or bind a string field and convert where you use it
> (`Number(this.selected)`). Binding a `number` field directly is a type error in
> `tsazor check`.
