---
title: Select bindings
keywords: @bind, select, dropdown, option
focus: App.tsazor
---

`selected` is `"mother"`, the dropdown shows the first option. Bind it:

```tsazor
<select @bind="selected">
```

The dropdown starts at the right option, and choosing another updates the paragraph. As in
Blazor, the select's value is applied after its options have been rendered (and re-applied
when they change), so options generated by `@foreach` are no problem.

> **Coming from Blazor:** as in Blazor, the selected value is converted to the field's
> type — Tsazor reads it by the value the field holds, so a `number` field (or a numeric
> enum) gets a number and a string field the option's text. A field that starts as `null`
> has no value to go by and gets the string.
