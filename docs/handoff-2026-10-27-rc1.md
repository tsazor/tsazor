## E9 code pre-audit (2026-10-27, three read-only reviews, the heaviest findings checked by hand)

About 90 findings: 1 blocker, ~30 major, the rest minor. Sound already: menu, dialog, tabs, calendar grid, combobox,
toolbar, the sortable table, charts with their data table.

### Wave 1 (before rc.1; each fix with a test)

1. `FluentForm` lacks `novalidate` (Bootstrap's `Form` has it): a `required` field shows the browser's bubble and
   blocks the submit, so EditForm never validates. A functional bug, not only a11y.
2. Toast (both skins): `role="alert"` with an explicit `aria-live="polite"` — danger toasts aren't assertive.
3. Spinner (both): "Loading…" only in `aria-label` of a `role=status`; live regions announce text, not names.
4. Tooltip (`ui/behaviors/tooltip.ts`): `aria-describedby` points at an element created on focus and removed on
   blur — missing in browse mode. Keep it in the DOM, hidden.
5. Focus lost to `<body>`: Paginator/Pagination at the first/last page (the focused button becomes disabled),
   removing an Autocomplete chip, closing a toast, ScrollToTop, AppLayout + Escape, Wizard Next → Done.
6. Bootstrap `Pagination` and `TimePicker` listbox: no default name (Fluent has `t(...)`).
7. DataGrid: the `<th>` name includes the grip, "Column options", the resize separator and an open filter panel;
   the group toggle's `aria-label` replaces the group value (WCAG 2.5.3).
8. DataGrid/Paginator: loading, filter and page results not announced.
9. Calendar (both): month change not announced (`aria-live` on the title).
10. `FocusOnInvalidSubmit` (runtime): first `[aria-invalid=true]` may be a fieldset or Rating's div — focus the first
    focusable one.
11. Chat: speaker marks "Y"/"A" hard-coded and `aria-hidden`; PromptInput's textarea has no name.
12. **SortableList (blocker for NVDA/JAWS):** focusable plain `<li>` — browse mode eats the keys; needs an
    interactive role.
13. Hard-coded English: FileUpload's count error, Chart's series/slice names, PromptInput's send label,
    AuthorizeRouteView's "Not authorized"/"Authorizing...", PivotDataGrid's "Rows"/"Total".

### Decisions (behavior changes; recommendation in brackets)

1. Toasts with an action stay until closed (WCAG 2.2.1) [yes].
2. `aria-invalid` as soon as the field shows invalid, not only after a submit; the message stays deferred [yes].
3. Runtime inputs tie their `ValidationMessage` with `aria-describedby` — additive, Blazor doesn't [yes].
4. Disabled menu items stay focusable (`aria-disabled`, APG); the gallery gate asserts the skip today [yes].
5. Single-character hotkeys (WCAG 2.1.4): document `enabled` as the way to turn them off [yes, no new behavior].
