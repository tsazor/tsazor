# @tsazor/ui

The behavior core of [Tsazor](https://github.com/tsazor/tsazor#readme)'s component libraries, without any styling: focus trap, dismiss,
roving focus, anchored positioning, tooltips and scroll lock as attachments; the models behind the data grid, tree,
combobox, calendar and the other complex components; ids, icon values (`icon()`, `IconValue`) and the shared
vocabulary of parameters. [`@tsazor/fluent`](https://www.npmjs.com/package/@tsazor/fluent) and [`@tsazor/bootstrap`](https://www.npmjs.com/package/@tsazor/bootstrap) are two skins over
it.

An app uses a skin. Build on `@tsazor/ui` when you write a component library of your own — see
[component libraries](https://github.com/tsazor/tsazor/blob/main/docs/component-libraries.md).
